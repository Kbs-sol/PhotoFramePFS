## 💰 PRICING STRATEGY (AOV = ₹650–750)

### Current Price Matrix:
| Size | Print Only | Framed |
|---|---|---|
| Small (8×10") | — | ₹499 |
| Medium (12×18") | — | ₹699 |
| Large (18×24") | — | ₹999 |
| XL (24×36") | — | ₹1,499 |

### To Push AOV to ₹700+:
1. **Bundle: 2 prints = 10% off** → avg bundle ₹699×2×0.90 = ₹1,258 → AOV spikes
2. **Gifting upsell** → +₹79 for gift wrapping + handwritten note (very high attach rate)
3. **Add A3 Poster add-on** → +₹89 per order (already implemented in code)
4. **Bundle: Frame + Poster** → "Gallery Starter Pack" at ₹1,199 (₹699 frame + ₹89 poster + ₹250 margin)
5. **Custom frame** → ₹699–₹1,499 (highest margin item)

### COD vs Prepaid Strategy:
- COD gets more orders (risk-averse Indian shoppers)
- Prepaid saves ₹49 (incentivize via ₹50 online discount)
- Goal: push prepaid to 40% → reduces RTO (return-to-origin) from 30%→15%

## 📦 SUPPLIER RELATIONSHIP (Moinabad)

### What to negotiate:
1. **MOQ (Minimum Order Quantity)** — Start with 1 frame/order. As volume grows, order 10–20 in advance to reduce per-unit cost
2. **Per-unit cost** — aim for frames at ₹120–200 (Small), ₹180–250 (Medium), ₹250–350 (Large)
3. **Turnaround time** — target 24-hour production once you provide the print file
4. **Quality control** — build a checklist: corner strength, glass clarity, print alignment, no air bubbles

### Print setup (what you need locally):
- **Epson EcoTank L8050** (₹25,000) — A4/A3 photo printer with pigment inks
- **Photo paper** — Satin, 240gsm (Amazon: ~₹2 per A4 sheet)
- Or: send files to a local photo lab (Digital Photo Express, etc.) for ₹20–50/print

### Cost breakdown per Medium (12×18") order:
| Item | Cost |
|---|---|
| Frame from Moinabad | ₹200 |
| Print (at lab) | ₹40 |
| Packaging (bubble wrap + box) | ₹30 |
| Shiprocket shipping | ₹60–80 |
| **Total COGS** | **₹370–350** |
| **Selling price** | **₹699** |
| **Gross margin** | **~50%** |
